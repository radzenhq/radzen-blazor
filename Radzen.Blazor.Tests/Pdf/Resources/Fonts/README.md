# Test font fixtures

All fonts licensed under the SIL Open Font License 1.1 (see LICENSE-OFL.txt).

- `LiberationSans-*.ttf`, `LiberationSerif-Regular.ttf`: Liberation Fonts 2.1.5 (c) Red Hat, unmodified.
- `Liberation-Subset.ttc`: TrueType collection built for tests from ASCII+Latin-1 subsets of Liberation Sans/Serif Regular (fonttools).
- `NotoSansSC-Subset.otf`: Noto Sans SC (c) Google, subsetted with fonttools to ASCII + Latin-1 + Cyrillic + an invoice CJK set, `--layout-features='*'` (GSUB/GPOS/BASE retained), CID-keyed CFF preserved.
