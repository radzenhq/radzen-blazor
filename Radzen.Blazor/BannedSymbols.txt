; WASM-safety / determinism guard for Radzen.Documents.Pdf.
; Enforced only under Documents/Pdf, Documents/Codes and Documents/Markdown
; (RS0030/RS0031 scoped to error in those trees via .editorconfig).
; The PDF library must reimplement crypto in pure managed code and stay deterministic:
; no System.Security.Cryptography algorithms/RNG, no wall-clock time, no Guid/Random entropy.

; --- System.Security.Cryptography: all algorithm / RNG / hashing / signing types ---
N:System.Security.Cryptography; Do not use System.Security.Cryptography in the PDF library - reimplement in pure managed WASM-safe code.
; Two carve-outs exist. Both are deterministic and available on every shipped target including
; browser-wasm, and both are suppressed with a local "#pragma warning disable RS0030" at their
; single call site; the analyzer has no allow-list, so a namespace ban plus a local suppression
; is the only way to express this.
;   1. CryptographicOperations.FixedTimeEquals - a constant-time comparison that no
;      reimplementation could improve on (Documents/Pdf/Objects/Encryption/StandardSecurityHandler.cs).
;   2. SHA1.HashData - the BCL SHA-1 backing Documents/Pdf/Crypto/Sha1.cs. It replaces a hand-rolled
;      implementation of the same RFC 3174 digest, which the ban was never meant to require.
;   3. SHA256/SHA384/SHA512.HashData and IncrementalHash - the BCL SHA-2 backing
;      Documents/Pdf/Crypto/Sha2.cs, for the same reason as SHA-1: a FIPS 180-4 digest is
;      deterministic and available on every shipped target.

; --- Non-deterministic wall-clock time ---
P:System.DateTime.Now; Non-deterministic. Do not use wall-clock time in the PDF library.
P:System.DateTime.UtcNow; Non-deterministic. Do not use wall-clock time in the PDF library.
P:System.DateTime.Today; Non-deterministic. Do not use wall-clock time in the PDF library.
P:System.DateTimeOffset.Now; Non-deterministic. Do not use wall-clock time in the PDF library.
P:System.DateTimeOffset.UtcNow; Non-deterministic. Do not use wall-clock time in the PDF library.

; --- Non-deterministic identifiers / entropy ---
M:System.Guid.NewGuid(); Non-deterministic. Do not generate Guids in the PDF library.
M:System.Random.#ctor(); Non-deterministic. Do not use System.Random in the PDF library.
M:System.Random.#ctor(System.Int32); Seeded Random is still banned to keep the PDF library RNG-free.
P:System.Random.Shared; Non-deterministic. Do not use System.Random in the PDF library.

; --- Networking: the PDF library must be self-contained and WASM/offline-safe (no sockets/HTTP) ---
N:System.Net; No network access in the PDF library - it must be self-contained and WASM-safe.
N:System.Net.Http; No HTTP access in the PDF library - it must be self-contained and WASM-safe.
N:System.Net.Sockets; No socket access in the PDF library - it must be self-contained and WASM-safe.
N:System.Net.Security; No network security stack in the PDF library - it must be self-contained and WASM-safe.
N:System.Net.NetworkInformation; No network access in the PDF library - it must be self-contained and WASM-safe.
N:System.Net.WebSockets; No network access in the PDF library - it must be self-contained and WASM-safe.
N:System.Net.Mail; No network access in the PDF library - it must be self-contained and WASM-safe.
T:System.Net.Http.HttpClient; No HTTP access in the PDF library - it must be self-contained and WASM-safe.

; --- Non-deterministic wall-clock / high-resolution timers ---
T:System.Diagnostics.Stopwatch; Non-deterministic timing. Do not measure wall-clock time in the PDF library.
P:System.Environment.TickCount; Non-deterministic. Do not read the system tick counter in the PDF library.
P:System.Environment.TickCount64; Non-deterministic. Do not read the system tick counter in the PDF library.

; --- Filesystem entropy / temp files (non-deterministic, not WASM-safe) ---
M:System.IO.Path.GetRandomFileName(); Non-deterministic. Do not generate random file names in the PDF library.
M:System.IO.Path.GetTempFileName(); Non-deterministic and not WASM-safe. Do not create temp files in the PDF library.
