# Gravatar

Demonstration and configuration of the Radzen Blazor Gravatar component.

> API reference: [RadzenGravatar API](https://blazor.radzen.com/api/gravatar.md)

## Examples

## Blazor Gravatar

Display user avatars based on email address.

### Gravatar with email (info)

Use it to display an image from a specified email.

```razor
<RadzenStack AlignItems="AlignItems.Center" class="rz-mx-auto rz-my-12">
    
    <RadzenGravatar Email="info@radzen.com" />

</RadzenStack>
```
