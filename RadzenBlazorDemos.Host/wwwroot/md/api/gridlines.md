# RadzenGridLines API Reference

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| LineType | `LineType` | Specifies the type of line used to render the grid lines. |
| Stroke | `string?` | Specifies the color of the grid lines. |
| StrokeWidth | `double` | Specifies the pixel width of the grid lines. Set to 1 by default. |
| Visible | `bool` | Specifies whether to display grid lines or not. Set to false by default. |
