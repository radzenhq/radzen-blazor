Create PDF tables in Blazor and C# with column and row spans, cell styling, relative column widths, and header rows that repeat on every page.

## Examples

## PDF Tables

Create tables with spanning cells, styled borders and backgrounds, relative column widths, and header rows that repeat when the table crosses a page.

### Basics

Build a table from columns, rows, and cells, and fill it from a list of objects.

### Spanning & cell styling

Merge cells with `ColumnSpan` and `RowSpan` and style them with borders, padding, background color, and vertical alignment.

### Tables across pages

Long tables paginate automatically. Mark rows with `IsHeaderRow` and `RepeatOnEveryPage` to repeat them after each break, keep rows together, and size columns with fixed or relative widths.
