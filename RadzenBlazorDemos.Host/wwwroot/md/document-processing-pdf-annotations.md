# Annotations

Add sticky notes, free text, shapes, ink, stamps, and text markup annotations to PDF documents in Blazor and C#.

Keywords: document, processing, pdf, annotation, note, comment, highlight, underline, strikeout, squiggly, stamp, ink, shape

## Examples

## PDF Annotations

Add review and markup annotations to pages - sticky notes, free text, shapes, ink strokes, stamps, and text markup - with appearances every viewer renders the same way.

### Annotation types

Sticky notes, free text, squares, circles, ink, stamps, and the text markup family - highlight, underline, strikeout, and squiggly - added with `Page.Annotations.Add`.

### Appearance

Set color, opacity, title, and flags. Appearance streams are generated for every annotation, so they render identically across viewers instead of depending on viewer defaults.
