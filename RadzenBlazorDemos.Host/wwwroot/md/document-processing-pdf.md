# Get Started

Create PDF documents in Blazor and C# - entirely in the browser, no server and no native dependencies. Build your first document and a complete invoice.

Keywords: document, processing, pdf, generate, create, invoice, report, browser, webassembly, wasm

## Examples

## Blazor PDF

Create PDF documents in Blazor and C#. The document engine is pure managed code with no native dependencies, so every demo on these pages runs entirely in your browser - the PDF is generated, displayed, and downloaded without touching a server.

### Hello world

Build a `Document`, add a section and a paragraph, and render it to PDF bytes with `DocumentRenderer`.

### Invoice

A complete invoice: named styles, a logo, seller and buyer address blocks, a line-item table with a repeating header row, totals, a payment QR code, and a footer with page numbers. Change the data and regenerate.
